# Overview
The button loading is component use for fetching data once button click. it will transform
to loading button while loading data

### Task
- create a button loading that accept isLoading boolean
- once the isLoading is true it should load a spinning icon
- accepted props: 
   - isLoading:boolean
   - variant: (fill,ghost,outline)
   - theme: (success,danger,primary,mute,secondary)
   - size: (large,icon,small,extra-small)
   - text:string
   - loadingText:string
   - icon:ReactNode
   - button props

### Style
- button should be rounded to small
- should have different size theme and variant
